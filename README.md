# ปตท.บ้านเชียงยืน — Station Monitor (3D)

เว็บ Dashboard แบบ 3D สำหรับดูภาพรวมปั๊ม เป็นไฟล์ static ล้วน (HTML + JS) ไม่ต้องมี server / build

```
index.html                 หน้าเว็บทั้งหมด (ฉาก 3D + การ์ด)
config.js                  ตั้งค่า API_URL / TOKEN  ← แก้ไฟล์นี้ที่เดียว
logos/                     โลโก้ PTT, Amazon, 7-Eleven (ใช้ทั้งบนป้าย 3D และไอคอนการ์ดยอดขาย)
google-apps-script/Code.gs สคริปต์ดึงข้อมูลจาก Google Sheet
sheet-templates/Station_Template.xlsx  เทมเพลต Google Sheet (มียอดย้อนหลัง)
```

ถ้ายังไม่ใส่ `API_URL` เว็บจะแสดง "ข้อมูลตัวอย่าง" ตามปกติ

## 1) ลองในเครื่อง
ห้ามเปิดไฟล์ด้วยการดับเบิลคลิก (โลโก้ใน 3D จะไม่ขึ้น) ให้รัน:
```
cd ptt-station-monitor
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000

## 2) ขึ้น GitHub Pages
1. สร้าง repo ใหม่ → อัปโหลดไฟล์ทั้งหมด (แตก zip แล้วลากเข้า)
2. Settings → Pages → Source: *Deploy from a branch* → Branch `main` / `/ (root)` → Save
3. รอ 1–2 นาที ได้ลิงก์ `https://<user>.github.io/<repo>/`

> repo แบบ Public = หน้าเว็บทุกคนเปิดได้ ส่วน Private ต้องใช้แผนที่รองรับ Pages
> ทางเลือกฟรี: Cloudflare Pages / Netlify (ลากโฟลเดอร์ขึ้นได้เลย)

## 3) เชื่อม Google Sheet (วิธีทำงานรายวัน)
**หลักการ:** กรอกยอดขายของ "เมื่อวาน" ลงชีตก่อน 11:00 ทุกวัน → เปิดเว็บเมื่อไรก็ได้ เว็บจะดึงข้อมูลล่าสุดมาแสดงเอง (ไม่ต้องเปิดค้าง)
เช่น วันที่ 14/09/2026 กรอกแถว 13/09/2026 → เว็บโชว์ "ยอดขาย 13 ก.ย. 69"

**3.1 สร้าง Sheet** — Google Drive → New → File upload → อัปโหลด `sheet-templates/Station_Template.xlsx` → เปิดด้วย Google Sheets → File → *Save as Google Sheets*
ในไฟล์มียอดย้อนหลังจากไฟล์เดิม (20/12/2025–30/09/2026) และวันที่ล่วงหน้าถึง 31/03/2027 แล้ว

| แท็บ | คอลัมน์ | หมายเหตุ |
|---|---|---|
| `คู่มือ` | – | วิธีกรอก (เว็บไม่อ่านแท็บนี้) |
| `daily` | A วันที่ · B น้ำมัน(ลิตร) · C น้ำมัน(คัน) · D น้ำมัน(บาท) · E Amazon(แก้ว) · F Amazon(บาท) · G 7-Eleven(คน) · H 7-Eleven(บาท) | 1 แถว = 1 วัน กรอกที่แถวของวันที่ขายจริง · แถวล่าสุดที่มียอด = "วันล่าสุด" · คอลัมน์ C (คัน) ยังไม่มีข้อมูลย้อนหลัง |
| `stock` | ชนิด · คงเหลือ(ลิตร) · พอขายอีก(วัน) | ช่องสีเหลือง · ว่าง = เว็บโชว์ `---` · วัน < `LOW_STOCK_DAYS` เตือนสีส้ม |
| `prices` | ชนิด · ราคา | ช่องสีเหลือง · ว่าง = ป้ายราคาโชว์ `--` |
| `rentals` | รหัส · ชื่อ · สถานะ · ค่าเช่า · หมายเหตุ | k1–k4 ร้านเช่า, r1–r2 ห้องเช่า · สถานะ: ว่าง / มีผู้เช่า / ซ่อม |

ห้ามแก้ชื่อแท็บและหัวตาราง (เพิ่มคอลัมน์อื่นทางขวาได้ เว็บไม่อ่าน) กรอกเป็นตัวเลขล้วน

**3.2 ติดตั้ง Apps Script**
1. ใน Sheet: *ส่วนขยาย → Apps Script* → ลบโค้ดเดิม วางเนื้อหา `google-apps-script/Code.gs`
2. แก้ `TOKEN` เป็นรหัสที่ตั้งเอง
3. *Deploy → New deployment → Web app* · Execute as: **Me** · Who has access: **Anyone** → Deploy → อนุญาตสิทธิ์
4. คัดลอก URL (ลงท้าย `/exec`)

**3.3 ใส่ใน config.js**
```js
API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
TOKEN: 'รหัสเดียวกับใน Code.gs',
```
commit / push → เปิดเว็บ ต้องเห็นชิปมุมขวาของแถบสรุป:
- เขียว "ข้อมูลวันที่ 13 ก.ย. 69" = ข้อมูลล่าสุดตามที่คาด
- เหลือง "ล่าสุด … · ยังไม่ได้อัปเดต" = ยังไม่ได้กรอกของเมื่อวาน (หลัง 11:00 ถ้าล่าสุดเก่ากว่าเมื่อวาน / ก่อน 11:00 ถ้าเก่ากว่าเมื่อวานซืน)
- แดง = เชื่อมไม่ได้ (ถ้าเคยโหลดสำเร็จ จะแสดงข้อมูลที่เก็บไว้ในเครื่อง)

ถ้าตั้ง `API_URL` แล้ว เว็บจะไม่ใช้ตัวเลขตัวอย่าง: ข้อมูลที่ยังไม่มีจะขึ้น `---`
ทดสอบ API: เปิด `API_URL?token=รหัส` ในเบราว์เซอร์ ต้องเห็น JSON
**แก้ Code.gs ภายหลังต้อง Deploy → Manage deployments → Edit → New version**

วิธีคิดตัวเลข (อิงวันล่าสุด L): วันล่าสุด = แถว L เทียบวันก่อนหน้า · 7/30 วัน = รวมย้อนหลังนับถึง L เทียบช่วงก่อนหน้าขนาดเท่ากัน · 12 เดือน = รวมรายเดือน เทียบยอดเฉลี่ยต่อวันของเดือนล่าสุดกับเดือนก่อน

## ความปลอดภัย (สำคัญ)
- URL และ TOKEN อยู่ในไฟล์ฝั่งหน้าเว็บ ใครเปิด DevTools ก็เห็น — token แค่กันการเดาลิงก์ ไม่ใช่ระบบล็อกอิน
- จึงให้ API ส่งเฉพาะตัวเลขที่รับได้ว่าคนเห็น (ราคา, สต๊อก, ยอดขาย) **อย่าใส่ต้นทุน/กำไร/ข้อมูลผู้เช่าที่เป็นความลับ**
- ถ้าต้องการจำกัดผู้เข้าชมจริง ให้วางเว็บหลัง Cloudflare Access หรือบริการ login

## ปรับแต่ง
- สีแบรนด์: ออบเจกต์ `CI` ใน `index.html`
- เปลี่ยนโลโก้: แทนไฟล์ใน `logos/` ชื่อเดิม (`pttm.png` = หยดน้ำ PTT, `sev7.png` = ตัว 7 ของ 7-Eleven ที่ใช้ในการ์ด)
- ตั้งราคาจากโค้ด: `window.setFuelPrices({G95:32,G91:30.8,E20:31.6,Diesel:28})`
- รอบรีเฟรช: `REFRESH_SECONDS`
